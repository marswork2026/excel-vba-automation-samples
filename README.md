# Excel Automation Samples（Excel業務自動化サンプル集）

Excel業務の自動化・効率化を専門に承っています。
「VBAが書ける人」ではなく「面倒なExcel作業を楽にする人」として、実務でよくある作業を自動化するサンプルをまとめています。

## できること

・複数ファイルのCSV結合・データ統合
・決まったフォーマットへの転記・データ整形
・月次/週次の集計作業の自動化
・帳票・レポートの自動作成

## サンプル一覧

| サンプル | 内容 | ファイル |
| --- | --- | --- |
| CSV結合 | 複数のCSV/Excelファイルを1つのシートに自動統合 | samples/csv_merge.bas |
| 月次集計 | 日次データから月次サマリーを自動集計 | samples/monthly_summary.bas |
| 帳票自動作成 | 元データからテンプレートに転記して帳票を出力 | samples/report_generator.bas |

## 依頼の流れ

手順1: 現状の作業内容と完成イメージをヒアリング
手順2: 無理のない範囲でマクロを作成
手順3: 納品・動作確認（修正1回込み）
